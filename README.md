## Что изменилось
- API-ключ теперь вводится прямо в приложении: **Настройки AI → OpenAI API key → Сохранить**.
- Пересобирать APK для смены ключа не нужно.

# Мой рацион AI — Android v0.2

Личная тестовая Android-сборка для распознавания еды и продуктов в холодильнике по фотографии.

## Что уже работает
- Kotlin + Jetpack Compose.
- Фото с камеры или выбор изображения из галереи.
- Два режима: «Еда» и «Холодильник».
- Прямой запрос к OpenAI Responses API с изображением.
- Модель по умолчанию: `gpt-6-luna` (дешёвый vision-capable вариант на момент сборки, октябрь 2026).
- Возврат списка найденных продуктов, примерной массы и confidence.
- Изображение уменьшается до 1280 px и JPEG 78%, `detail=low`, чтобы снизить расход.

## Как добавить ключ
1. Открой проект в Android Studio.
2. В корне проекта создай/открой `local.properties`.
3. Оставь строку `sdk.dir=...`, которую создаёт Android Studio.
4. Добавь новую строку:

   `API key (entered inside the app)=sk-...`

5. Sync Project with Gradle Files и запусти приложение.

`local.properties` уже находится в `.gitignore`, поэтому ключ не попадёт в GitHub.

## ВАЖНО про безопасность
Это сделано только для личного прототипа. При сборке значение ключа попадает внутрь APK через BuildConfig и может быть извлечено из APK. Не публикуй и не передавай APK с действующим ключом. Перед публичным релизом API-вызов надо перенести на backend и перевыпустить ключ.

## Ограничения MVP
- Масса по одной фотографии — только оценка.
- Результат AI нужно подтверждать вручную.
- Дневник, локальная БД, полноценный расчёт КБЖУ и рецепты будут следующим этапом.

## Сборка
Проект рассчитан на Android Studio с JDK 17. Gradle Wrapper в архив не включён, поэтому при первом открытии Android Studio должна выполнить Gradle Sync с доступом в интернет.
