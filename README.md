# Мой рацион AI — Android v0.4

Обновлённая личная Android-сборка проекта питания с AI-распознаванием еды.

## Что есть в v0.4
- Новый интерфейс с нижней навигацией: **Сегодня / AI-скан / Профиль**.
- Цели: снижение веса, поддержание или набор веса.
- Дневной ориентир калорий с индикатором прогресса.
- Локальный дневник приёмов пищи на время текущего запуска приложения.
- Фото с камеры или из галереи.
- Режимы **Еда** и **Холодильник**.
- AI определяет продукты, приблизительную массу, калории и БЖУ, а также confidence.
- Результат можно добавить в дневник одним нажатием.
- API-ключ вводится прямо в приложении и шифруется через Android Keystore.
- Прямой запрос Android → OpenAI Responses API оставлен для личного прототипа.

## AI
Модель по умолчанию: `gpt-6-luna`. Фото уменьшается до 1280 px, JPEG 78%, `detail=low`, чтобы уменьшить стоимость обработки.

## Сборка через GitHub Actions
Workflow `.github/workflows/android.yml` автоматически собирает debug APK при push в `main` и сохраняет его как artifact `MyRationAI-debug-apk`.

Открой вкладку **Actions → Android APK → последний запуск → Artifacts**, чтобы скачать APK.

## Важно
Распознавание продуктов, массы и КБЖУ по одной фотографии является приблизительным. Пользователь должен проверить результат перед сохранением. Приложение не предназначено для медицинской диагностики и не оценивает внешность.

Для публичного приложения API-вызовы нужно перенести на backend: мобильное приложение не является безопасным местом для общего секретного API-ключа.
